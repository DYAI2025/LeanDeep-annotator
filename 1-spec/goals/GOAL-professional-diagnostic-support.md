# GOAL-professional-diagnostic-support

**Priority**: Must-have  
**Status**: Approved  
**Source Stakeholder**: STK-product-owner, STK-researcher

## Objective

Enable therapeutic professionals (Therapeuten, Psychologen, Coaches) to use LeanDeep as a **diagnostic support tool** to counteract personal biases, recognize new patterns, and gain evidence-based insights through marker detection and narrative analysis.

## Success Criteria

- [ ] Markers are clearly named and interpretable by professionals
- [ ] Pattern frequency and clustering provides bias-check feedback
- [ ] Marker narrative contexts enable pattern recognition
- [ ] System surfaces alternative interpretations (to counteract single-perspective bias)
- [ ] CLU clusters highlight meaningful psychological/conversational patterns
- [ ] Professional users report >= 80% confidence in marker accuracy
- [ ] Tool reduces decision time vs manual analysis by >= 50%

## Key Features

1. **Clear Marker Semantics**: Each marker has interpretable meaning for professionals
2. **Pattern Recognition**: Repeated markers across dialogue show behavioral patterns
3. **Bias Counteraction**: Multiple narrative perspectives challenge single-view bias
4. **Evidence Grounding**: Markers are grounded in text (not speculative)
5. **Professional Confidence**: System explains its reasoning (transparency)

## Target Users

- Therapeuten (Psychotherapeuten)
- Psychologen
- Coaches
- Forensische Analysten
